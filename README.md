# マダミス時系列整理

マーダーミステリー（マダミス）専用の、**時系列・人物整理メモアプリ**です。
「誰が・いつ・何をしていたか」を書き溜めて、推理を組み立てるためのツールです。

- **1枚のHTMLファイルだけ**で動作します（インストール不要）。
- データはお使いの**ブラウザの中（localStorage）に自動保存**されます。
- インターネット接続は不要。ファイルをダブルクリックで開くだけで使えます。

---

## はじめかた（3ステップ）

1. `マダミス時系列整理.html` をブラウザで開きます（ファイルをダブルクリック）。
2. 「時間」「人物」「できごと」を入れて **［追加］** を押すと1件登録されます（**できごとだけは必須**）。
3. 入力した内容は自動で保存され、**時間の早い順に自動で並びます**。

> 💡 アプリ内の右上にもヘルプ（❓）があり、いつでも使い方を確認できます。

---

## 基本の使い方

### 出来事を登録する
- 「時間」「人物」「できごと」を入力して **［追加］**。**できごとは必須**です。
- **人物は複数選べます**。「人物 ▾」からチェックを入れると、同じ出来事に複数人を紐づけられます。
- 時間は `20:5` のように分が1桁でも `20:05` に自動補完されます。
- 時間欄は「夕方」「翌朝」「不明」など **自由な言葉でも登録できます**。時刻で入れたものは早い順、言葉で入れたものは末尾にまとまります。

### キャラクターを先に登録しておく
- **「👤 キャラクター一覧」** でキャラを登録しておくと、人物選びが楽になります。
- キャラ名の横の **色ボタン** からカラーパレットで色を選べます（1人だけのカードはその色で色分けされます）。

### カードのボタン
登録済みカードの右下には次のボタンが並びます。

| ボタン | できること |
| --- | --- |
| ✏️ 編集 | 時間・終了時刻・できごとの内容を修正（✓保存／✕取消） |
| 👥 登場人物 | 後から人物を追加・削除 |
| 🚩 フラグ | 重要フラグ（左端の金色の線）のON/OFF |
| 👁️ 表示/非表示 | できごとの中身を隠す（ネタバレ隠しに便利） |
| 🎨 色を隠す/戻す | そのカードの色分けだけを一時的に消す |
| ✕ 削除 | そのカードを削除 |

## 便利な機能

### ⏱ 期間（開始〜終了）で登録
- 入力欄の **「⏱ 期間」** を押すと終了時刻の欄が現れます。開始と終了を入れると **「開始〜終了」を示すカード** になります。
- 期間の途中に別の出来事があると、自動で開始・終了カードに分かれ、**右側の縦ラインでつながって見え**、「この間ずっと〜していた」が一目でわかります。
- 終了が開始より前のときは、日付を跨ぐ範囲（例: 23:00〜翌1:00）として扱われます。

### ⚰️ 死亡推定時刻
- 時系列の右上のプルダウンで開始〜終了の時刻を決め、ボタンを **ON** にします。
- ONにすると、その時間帯に含まれる出来事の **左端に赤い線** が付きます。

### 👥 絞り込み
- 時系列の上の **絞り込みバー** で人物を選ぶと、その人物が登場するカードだけ表示（複数選択可、「全員」で解除）。
- **「🚩フラグつき」「フラグなし」** でも絞り込めます。

### 📋 リスト表示 と 📊 人物比較表示
- 時系列の上の **「📋 リスト」／「📊 人物比較」** で表示を切り替えられます。
- **📊 人物比較**：左端に時間、上に人物名を並べ、「誰がいつ何をしていたか」を横並びで見比べられます。
  - 人物名の左右の **⬅︎ ➡︎** で列の並び順を入れ替え。
  - **「人物の並びを固定する」** で並び順を保存。
  - **「表示倍率」の −／＋** で比較表の大きさを変更（この画面だけの設定）。

### 🎭 セッション名・📝 秘密のメモ
- 左上の **セッション名** をクリックすると編集でき、作品タイトルなどを入れられます。
- **📝 秘密のメモ** に自分の推理を自由に書けます（自動保存）。**👁️** でメモ全体を隠せます。

## データの保存・持ち運び

- 入力した内容は **この端末のブラウザに自動保存** されます。
- 別のブラウザ・別のPCへは自動では引き継がれません。
- 画面上部の **「▶︎ セッションデータ」** から次の操作ができます。
  - **⬆️ 書き出し**：すべてのデータをファイルに保存（バックアップ・共有用）。
  - **⬇️ 取り込み**：書き出したファイルを読み込み、今のデータを置き換え。
  - **一括削除**：全キャラクター／全タイムライン／全データを削除（元に戻せないので注意）。

> ⚠️ 保存先はブラウザの localStorage です。ブラウザの「サイトデータ／履歴の削除」を行うと保存内容も消えます。**大切なデータはこまめに書き出してバックアップ**することをおすすめします。
>
> ⚠️ また、**HTMLファイルの置き場所（フォルダ）やファイル名を変えると、ブラウザによっては保存データが見えなくなる場合があります**（データ自体は消えていなくても、別の場所の保存領域として扱われるため）。移動・改名の前に書き出してください。同じファイルでも Chrome と Safari などブラウザが違うとデータは共有されません。

## 動作環境

- **Google Chrome / Microsoft Edge / Safari**：現行版で全機能が利用できます。
- ブラウザの最低バージョンの目安：**Chrome / Edge 80以降、Safari 13.1以降、Firefox 74以降**。これより古いブラウザ（古いAndroid端末に残った更新前のChrome・WebViewなど）では画面が動作しないことがあります。
- **Firefox**：現行版（バージョン126 / 2024年5月以降）で全機能が利用できます。
  - 2024年5月より前の古いFirefoxはズーム機能（CSS zoom）に未対応のため、「人物比較」ビューの表示倍率を**別方式（transform: scale）で自動的に代替**します（対応可否を自動判定。最新ブラウザの動作は従来どおり）。代替時は拡大・縮小の際に表の下側へ余白が出るなど、表示が僅かに乱れることがあります。気になる場合は最新版に更新するか、Chrome / Edge / Safari をご利用ください。
- インターネット接続は不要です。`file://`（ローカルファイル）のまま動作します。
- **📱 スマホ版／💻 PC版** は画面右上で切り替えられます（狭い画面では自動でスマホ版の見た目になります）。

### 絵文字・記号の表示について（OS間の互換性）

本アプリは、OSが違ってもボタン・絵文字・チェックマークの見た目・位置が崩れにくいよう、次の対策を入れています。

- 各OSのシステムフォント＋カラー絵文字フォント（Apple Color Emoji / Segoe UI Emoji / Noto Color Emoji）を明示指定し、絵文字の豆腐化（□）を防止。
- ボタン・入力欄はOS既定のUIフォントではなく本文と同じフォントを使うよう統一（ボタン内の文字・絵文字の位置ズレ防止）。
- カラーで見せたい絵文字（✏️🚩👁️⬆️⬇️🗑️など）には絵文字用、モノクロで見せたい記号（▶︎⬆︎⬇︎⬅︎➡︎↩︎）にはテキスト用の異体字セレクタを付与し、Windowsで勝手にカラー絵文字化／Androidで勝手にモノクロ化するのを抑制。
- チェックボックスはサイズを固定し、iOS/Androidの自動文字拡大も無効化。

#### それでも完全には同じにならない点（既知の制限）

- **カラー絵文字のデザインそのもの**（🚩の旗の形、👁️の目の絵など）はOS付属の絵文字フォントに依存するため、Windows／mac／Androidで絵柄は変わります（位置とサイズは崩れません）。
- **🚩のグレー表示（OFF状態）**はCSSの`grayscale`フィルタで実現しており、ごく古いブラウザ（IEなど）では常にカラーで表示されます。
- **Android 7以前の古い端末**では、モノクロ記号（⬆︎⬇︎⬅︎➡︎↩︎）のモノクロ字形がフォントに含まれておらず、カラー絵文字で代用表示されることがあります（ボタンサイズは固定のためレイアウトは崩れません）。
- **Windows 7/8＋古いブラウザ**の組み合わせでは、一部の絵文字（🧹など比較的新しいもの）が□で表示されることがあります。Windows 10以降＋現行ブラウザでは問題ありません。
- 推奨環境：**Windows 10以降 / macOS / iOS / iPadOS / Android 8以降** × 現行の Chrome / Edge / Safari / Firefox。この範囲ではレイアウト・ボタン位置・記号の表示が崩れないことを想定した設計になっています。
