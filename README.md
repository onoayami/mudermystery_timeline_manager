# マダミス時系列整理

マーダーミステリー（マダミス）専用の、時系列・人物整理メモアプリです。
1枚のHTMLファイルだけで動作し、データはお使いのブラウザ内（localStorage）に保存されます。

## 使い方

1. `マダミス時系列整理.html` をブラウザで開きます（ダブルクリックで開けます）。
2. キャラクター・できごと・死亡推定時刻などを入力すると、自動で保存されます。
3. 「📋 リスト」と「📊 人物比較」の2つの表示を切り替えて確認できます。

- データはファイルを開いたブラウザの中だけに保存されます。別のブラウザや別のPCへは自動では引き継がれません。
- 引き継ぎたいときは、画面のエクスポート／インポート機能でファイルとして持ち運べます。

## 動作環境

- **Google Chrome / Microsoft Edge / Safari**: 現行版で全機能が利用できます。
- **Firefox**: 現行版（バージョン126 / 2024年5月以降）で全機能が利用できます。
  - **注意**: 2024年5月より前の古いFirefoxでは、「人物比較」ビューの**拡大・縮小（ズーム）だけが効きません**。
    （表示が崩れることはなく、倍率が変わらないだけです。ほかの機能は問題なく使えます。）
    気になる場合は、Firefoxを最新版に更新するか、Chrome / Edge / Safari をご利用ください。
- インターネット接続は不要です。`file://`（ローカルファイル）のまま動作します。

## データについて

- 保存先はブラウザの localStorage です。ブラウザの「サイトデータ／履歴の削除」を行うと、保存内容も消えます。
- 大切なデータは、こまめにエクスポートしてバックアップを取ることをおすすめします。
